# cloudrouzan.com — starter

A minimal React + TypeScript + Vite personal website.

## Develop locally

Install Node.js (current LTS), then:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Build

```bash
npm run build
```

The static production site is in `dist/`.

## Make it yours

- Edit text and links in `src/main.tsx`.
- Edit styling in `src/styles.css`.
- Replace the placeholder LinkedIn link with your actual profile URL.
- Add projects when you're ready.

## Deploy

Commit this folder to GitHub and import the repository into your preferred static hosting provider (e.g. Cloudflare Pages or Vercel). Use build command `npm run build` and output directory `dist`. Connect the custom domain only after the preview deployment works. Keep the Squarespace domain registration and auto-renewal in place.
